# Roadmap

## Now: MVP foundation

- Tauri desktop shell.
- Local profile and project roots.
- VS Code-inspired workspace.
- Agent explain/plan/edit/diagnose flows.
- AI SDK gateway boundary.
- LangChain orchestration and checkpoints.
- Explicit MCP registration and approvals.
- Lightweight coworking context.

## Next: Team workflows

- Optional hosted sync for project metadata and presence.
- Shared task/run summaries with privacy controls.
- Team policies for models, tools, and budgets.
- Review links for patch proposals.
- Workspace templates.

## Later: Coworking operations

- Desk and room availability.
- Reservations and check-in.
- Events and community directory.
- Workspace operator console.

## Later: Advanced agent platform

- Multi-agent delegation with explicit budgets.
- Background jobs and scheduled maintenance.
- Remote sandboxes.
- Organization SSO and policy administration.
- Evaluation datasets and regression scoring.

## Release gates

- No phase advances with unresolved critical security findings.
- No autonomous write/execute behavior without a named approval policy.
- No cloud sync claims before conflict, deletion, and privacy semantics are specified.
